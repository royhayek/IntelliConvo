Dear Envato Reviewer,

Thank you for reviewing IntelliConvo. This is a complete, production-ready AI chatbot SaaS platform built with modern technologies.


SETUP:
======

Backend (port 5000):
- cd backend
- npm install
- npx prisma generate
- npx prisma migrate dev
- npm run dev

Frontend (port 3000):
- cd frontend
- npm install
- npm run dev

Widget (port 8080):
- cd widget
- npm install
- npm run serve

========================

1. Register a new user account at http://localhost:3000/register
2. Login and create a new "Site"
3. Add a website URL to crawl (e.g., https://example.com)
4. Wait for crawling to complete (background job via BullMQ)
5. Copy the widget embed code provided
6. Test the widget by adding it to any HTML page
7. Chat with the AI - it will respond based on crawled content

THIRD-PARTY REQUIREMENTS:

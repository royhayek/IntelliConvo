A) Introduction & Features - top

IntelliConvo is a complete SaaS platform for creating AI-powered chat widgets that can be embedded on any website. It uses OpenAI's GPT models to provide intelligent, context-aware responses based on your website's content.

Key Features

  • AI-Powered Chat: Uses OpenAI GPT-4 and GPT-3.5 models for intelligent responses
  • Website Crawling: Automatically crawls and indexes website content for context
  • Vector Search: Semantic search using Pinecone for accurate content retrieval
  • Customizable Widget: 100+ customization options for appearance and behavior
  • Multi-tenant SaaS: Support for unlimited users with separate sites
  • Subscription Billing: Stripe integration with trial support
  • OAuth Authentication: Google, GitHub, and Microsoft login options
  • Knowledge Base: Upload PDFs and documents for additional context
  • Real-time Chat: Socket.io powered real-time messaging with streaming
  • Analytics: Conversation tracking, usage metrics, and cost analysis
  • Admin Dashboard: Complete admin panel for user and site management

Technology Stack

  • Backend: Node.js, Express, TypeScript, Prisma ORM
  • Frontend: Next.js 14, React 18, Tailwind CSS, Radix UI
  • Widget: Vanilla TypeScript, Webpack (single embeddable file)
  • Database: PostgreSQL
  • Cache/Queue: Redis with BullMQ
  • AI: OpenAI GPT-4/3.5, text-embedding-3-small
  • Vector DB: Pinecone
  • Payments: Stripe

C) Installation (Docker - Recommended) - top

Recommended: Docker installation is the easiest and most reliable method. It handles all dependencies automatically.

Step 1: Extract Files

1 Extract the downloaded ZIP file to your server: 
# Upload and extract
unzip intelliconvo.zip -d /var/www/
cd /var/www/intelliconvo

Step 2: Configure Environment

2 Copy the environment template and configure your settings: 
# Copy environment template
cp .env.docker.example .env

# Edit with your values
nano .env

At minimum, you must configure:

  • JWT_SECRET - A random 32+ character string
  • OPENAI_API_KEY - Your OpenAI API key
  • PINECONE_API_KEY - Your Pinecone API key
  • POSTGRES_PASSWORD - Secure database password

Step 3: Start Services

3 Build and start all services: 
# For production (with nginx reverse proxy)
docker-compose -f docker-compose.prod.yml up -d --build

# OR for simple setup (separate ports)
docker-compose up -d --build

Step 4: Verify Installation

4 Check that all services are running: 
# Check status
docker-compose ps

# View logs
docker-compose logs -f

server {
    listen 80;
    server_name yourdomain.com;

    # Frontend
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # Backend API
    location /api/ {
        proxy_pass http://localhost:5001;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # Socket.io
    location /socket.io/ {
        proxy_pass http://localhost:5001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    # Widget
    location /widget/ {
        alias /var/www/intelliconvo/widget/dist/;
        add_header Access-Control-Allow-Origin *;
    }
}
# Enable site

Important - Monorepo Setup: This project is a monorepo containing backend/, frontend/, and widget/ folders. When deploying from GitHub, you must manually select the correct Root Directory for each service. Both Railway and Vercel will prompt you to configure this after selecting the repository.

Step 1: Deploy Backend on Railway

1.1: Create Railway Account
  1. Go to railway.app and sign up
  2. Connect your GitHub account
1.2: Create New Project
  1. Click "New Project" to create an empty project
  2. You'll add services to this project in the following steps
1.3: Add PostgreSQL Database
  1. In your project, click "New" → "Database" → "Add PostgreSQL"
  2. Railway will automatically provision the database
  3. The DATABASE_URL will be automatically available to linked services

Manual Configuration: If the variable isn't automatically injected, click on the PostgreSQL service, go to "Connect" tab, copy the connection string, then add it manually to your backend service's Variables as DATABASE_URL.

1.4: Add Redis
  1. Click "New" → "Database" → "Add Redis"
  2. Railway will provision Redis automatically
  3. The REDIS_URL will be automatically available to linked services

Manual Configuration: If the variable isn't automatically injected, click on the Redis service, go to "Connect" tab, copy the Redis URL, then add it manually to your backend service's Variables as REDIS_URL.

1.5: Add Backend Service
  1. Right-click in your project canvas and select "Add New Service" → "GitHub Repo"
  2. Select your IntelliConvo repository from the list
1.6: Configure Backend Service
  1. Click on the backend service you just added
  2. Go to the "Settings" tab
  3. In the Source section:
    • Set Root Directory to /backend
  4. In the Networking section:
    • Click "Generate Domain" to create a public URL for your backend
    • Save this URL - you'll need it for the frontend and widget configuration
  5. In the Build section:
    • Set Builder to Dockerfile
    • Set Dockerfile Path to /backend/Dockerfile
    • In Watch Paths, enter /backend/** so that only backend code changes trigger a new deploy
1.7: Add Environment Variables

Go to the "Variables" tab and add the following:

M) Troubleshooting & FAQ - top

Common Issues

1. "Database connection refused"

Cause: PostgreSQL is not running or credentials are wrong.

Solution:

# Check PostgreSQL status
sudo systemctl status postgresql

# Test connection
psql -h localhost -U postgres -d intelliconvo

# Docker: check container
docker logs intelliconvo-postgres
2. "Redis connection failed"

Cause: Redis is not running.

Solution:

# Check Redis status
sudo systemctl status redis
redis-cli ping

# Docker: check container
docker logs intelliconvo-redis
3. "OpenAI API error"

Cause: Invalid API key or insufficient credits.

Solution:

  • Verify API key is correct in .env
  • Check OpenAI account has credits
  • Verify API key has correct permissions
4. "Widget not loading"

Cause: CORS issues or wrong widget URL.

Solution:

  • Verify WIDGET_CDN_URL matches where widget is hosted
  • Check browser console for CORS errors
  • Ensure site ID in embed code is correct
5. "Crawling stuck or failing"

Cause: Website blocking bots or JavaScript rendering issues.

Solution:

  • Check website allows crawling (robots.txt)
  • Some sites require JavaScript rendering - this is handled automatically
  • Check backend logs for specific errors
6. "Stripe webhook not working"

Cause: Wrong webhook URL or secret.

Solution:

  • Verify webhook URL is correct: https://yourdomain.com/api/v1/webhooks/stripe
  • Ensure STRIPE_WEBHOOK_SECRET matches Stripe dashboard
  • Check all required events are selected
  • For local testing, use Stripe CLI

Log in with default credentials, go to Account Settings, and change your password. Or set ADMIN_EMAIL and ADMIN_PASSWORD environment variables before first run.

Currently, all AI requests use the platform's OpenAI key. Per-user keys would require code modification.

O) Rebranding Guide - top

This guide explains how to rename "IntelliConvo" to your own brand name throughout the application.

Overview

Difficulty: Easy to Moderate
Skills Required: Basic find-and-replace, command line usage

Visual Assets to Replace

1. Favicon
FileDescription
frontend/app/favicon.ico Browser tab icon (recommended: 32x32 or 48x48 pixels)

How to replace: Create your favicon at favicon.io or realfavicongenerator.net, then replace the file.

2. Brand Logo
FileDescription
frontend/components/ui/brand-logo.tsx Main logo component used throughout the dashboard. Contains "IC" letters and "IntelliConvo" text.
frontend/components/icons/intelliconvo-icon.tsx Icon-only version of the logo (for compact displays)

How to customize:

  • Change the "IC" letters in the chat bubble to your brand initials
  • Update the "IntelliConvo" text to your brand name (line 188 in brand-logo.tsx)
  • Modify gradient colors (from-indigo-600 to-purple-600) to match your brand
  • Or replace the entire component with your own SVG/image logo
3. Brand Colors
FileWhat to Change
frontend/app/globals.css CSS custom properties for theme colors
frontend/tailwind.config.ts Tailwind color configuration (if extended)

Key color variables in globals.css:

:root {
  --primary: 239 84% 67%;        /* Main brand color (indigo) */
  --primary-foreground: 210 40% 98%;
  --ring: 239 84% 67%;           /* Focus ring color */
}

/* Gradient used in logo and accents */
.gradient-brand {
  @apply bg-gradient-to-br from-indigo-600 via-purple-600 to-blue-700;
}
4. Email Templates
FileWhat to Change
backend/src/services/email/templates/baseLayout.ts Email header, footer, and brand colors

Key settings in baseLayout.ts:

// Default values - customize these
platformName = 'IntelliConvo',        // Your brand name
supportEmail = 'support@intelliconvo.com',  // Your support email
primaryColor = '#6366f1',             // Your brand color (hex)
5. Metadata & SEO
FileWhat to Change
frontend/app/layout.tsx Site title, description, and metadata 
export const metadata: Metadata = {
  title: "YourBrand - AI Chat Assistant for Websites",
  description: "Your custom description here.",
};

Step-by-Step Process

Step 1: Search for All Occurrences

First, find all files containing the brand name:

# macOS/Linux
grep -r "intelliconvo" --include="*.ts" --include="*.tsx" --include="*.json" --include="*.md" .

# Windows (PowerShell)
Get-ChildItem -Recurse -Include *.ts,*.tsx,*.json,*.md | Select-String -Pattern "intelliconvo"
Step 2: Replace in Backend 
cd backend

# Update package.json name
# Update prisma/seed.ts admin email
# Update any email templates in src/templates/
Step 3: Replace in Frontend 
cd frontend

# Update package.json name
# Update app/layout.tsx metadata
# Update components/ui/logo.tsx
# Search and replace in all .tsx files
Step 4: Replace in Widget (Careful!) 
cd widget

# Update package.json name
# Update window.intelliconvo in src/index.ts
# Update CSS class prefixes throughout src/

# IMPORTANT: Update the embed code pattern
# Old: window.intelliconvo('init', {...})
# New: window.yourbrand('init', {...})
Step 5: Update Docker Configuration 
# Update container names in:
# - docker-compose.yml
# - docker-compose.dev.yml
# - docker-compose.prod.yml

# Example: intelliconvo-backend → yourbrand-backend
Step 6: Rebuild Everything 
# Rebuild widget
cd widget && npm run build

# If using Docker, rebuild all containers
docker-compose down
docker-compose up -d --build

Update Embed Code

After rebranding, update your widget embed code instructions:

<script>
  (function() {
    var script = document.createElement('script');
    script.src = 'https://yourdomain.com/widget/widget.js';
    script.async = true;
    script.onload = function() {
      window.yourbrand('init', {  // Changed from 'intelliconvo'
        siteId: 'your-site-id',
        apiUrl: 'https://yourdomain.com'
      });
    };
    document.head.appendChild(script);
  })();
</script>

Testing After Rebranding

  1. Start all services and verify no errors in console
  2. Check frontend loads with correct title/branding
  3. Test widget initialization with new global function name
  4. Verify emails send with correct branding
  5. Check all pages display correctly

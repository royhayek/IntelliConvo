# Screenshot Guide for CodeCanyon Preview Images

This guide will help you create professional preview images for your CodeCanyon submission using the HTML templates provided.

---

## 📋 What You Need

1. `preview-image-template.html` - Main preview image (1200x630px)
2. `thumbnail-template.html` - Thumbnail icon (80x80px)
3. A modern web browser (Chrome, Firefox, or Safari recommended)
4. Screenshot tool or browser dev tools

---

## 🖼️ Method 1: Main Preview Image (1200x630px)

### Using Browser Developer Tools (Recommended)

1. **Open the template:**
   - Double-click `preview-image-template.html` to open it in your browser
   - OR right-click → Open With → Your preferred browser

2. **Open Developer Tools:**
   - **Windows/Linux:** Press `F12` or `Ctrl + Shift + I`
   - **Mac:** Press `Cmd + Option + I`

3. **Take a full-page screenshot:**
   - **Chrome/Edge:**
     - Press `Ctrl + Shift + P` (Windows) or `Cmd + Shift + P` (Mac)
     - Type "screenshot"
     - Select "Capture full size screenshot"
     - Image will download automatically

   - **Firefox:**
     - Click the three dots menu (⋯) in dev tools
     - Click "Take a screenshot"
     - Click "Save full page"

   - **Safari:**
     - Use macOS built-in screenshot tool (see Method 2 below)

4. **The downloaded image should be 1200x630px** - perfect for CodeCanyon!

### Using Built-in Screenshot Tools

#### macOS:
```bash
# Take a screenshot of selected area
1. Open preview-image-template.html in browser
2. Press Cmd + Shift + 4
3. Press Space bar to switch to window capture mode
4. Click on the browser window
5. Image will save to Desktop
```

#### Windows:
```bash
# Using Snipping Tool
1. Open preview-image-template.html in browser
2. Press Windows + Shift + S
3. Select "Window Snip"
4. Click on the browser window
5. Save the screenshot
```

## 🎨 Method 2: Thumbnail Image (80x80px)

### Quick Method:

1. **Open the thumbnail template:**
   - Double-click `thumbnail-template.html`

2. **Take screenshot of just the colored square:**

   **macOS:**
   - Press `Cmd + Shift + 4`
   - Drag to select only the colored square (80x80px)
   - Release mouse button
   - Image saves to Desktop

   **Windows:**
   - Press `Windows + Shift + S`
   - Select "Rectangular Snip"
   - Drag around the colored square
   - Click save icon
   - Save as PNG or JPEG

3. **Verify dimensions:**
   - Right-click the saved image → Get Info (Mac) or Properties (Windows)
   - Should be exactly 80x80 pixels
   - If not, resize using any image editor

## 🛠️ Alternative Method: Using Image Editing Software

If you want more control or need to adjust colors/text:

### Using Photoshop/GIMP/Figma:

1. **Take screenshot using methods above**
2. **Open in image editor**
3. **Crop/resize to exact dimensions:**
   - Main preview: 1200 x 630 pixels
   - Thumbnail: 80 x 80 pixels
4. **Adjust colors if needed** (match your brand)
5. **Export:**
   - Format: JPEG or PNG
   - Quality: High (80-90% for JPEG)
   - File size: Keep under 2MB for preview, under 100KB for thumbnail

## 🎯 Pro Tips

1. **Use High-Resolution Display:**
   - If available, use a Retina/4K monitor for crisp screenshots
   - Or use browser zoom at 200% then resize to 1200x630

2. **Compress Images:**
   - Use [TinyPNG](https://tinypng.com/) to compress without quality loss
   - Can reduce file size by 60-80%
   - Faster load times = better user experience

3. **Test at Different Sizes:**
   - View your preview image at small size (like in search results)
   - Make sure text is still readable

4. **A/B Test:**
   - Create 2-3 variations of the preview
   - Ask friends/colleagues which one looks better
   - Choose the most eye-catching one

5. **Consistency:**
   - Use the same color scheme across preview and thumbnail
   - Maintain brand consistency

## 🔧 Troubleshooting

### "Screenshot is not 1200x630"
- **Solution:** Use browser dev tools screenshot method (most accurate)
- Or manually resize in image editor to exactly 1200x630px

### "Colors look different in screenshot"
- **Solution:** Check your monitor color calibration
- Or use color picker to match exact hex values

### "Text is blurry"
- **Solution:** Take screenshot at higher resolution
- Use browser zoom at 200%, then resize to 1200x630
- Make sure you're using a high-DPI display

### "File size too large"
- **Solution:** Compress using TinyPNG or similar tool
- Export as JPEG with 80-85% quality
- Remove unnecessary transparency (use JPEG instead of PNG)

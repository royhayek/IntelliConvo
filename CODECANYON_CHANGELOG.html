Complete Feature List

  • Full SaaS platform with user authentication and role management
  • Website crawling and automatic content indexing with BullMQ queues
  • AI-powered chat widget with GPT-4 and GPT-3.5 support
  • Vector search using Pinecone for semantic content retrieval
  • 100+ widget customization options for appearance and behavior
  • Stripe subscription billing with monthly and annual plans
  • OAuth authentication (Google, GitHub, Microsoft)
  • Complete admin dashboard for user and site management
  • Knowledge base with PDF and document uploads
  • Real-time chat with Socket.io streaming responses
  • Conversation analytics, usage metrics, and cost tracking
  • Email notifications with customizable templates
  • Docker support for easy deployment
  • Comprehensive API with Swagger documentation

## Customer Update Summary

### Minimal Downtime Update (5-10 minutes)
```bash
1. Backup database and files
2. Stop services
3. Copy new files
4. Run: npx prisma migrate deploy
5. Rebuild frontend/widget
6. Restart services
7. Test functionality
```

### Zero-Downtime Blue-Green Deployment
```bash
1. Deploy v1.0.1 to new server (green)
2. Run migrations on shared database
3. Test green server
4. Switch load balancer
5. Monitor
6. Decommission old server after 24-48h
```

## Technical Details

### New Socket.IO Events
- `message-routed-to-agent` - Acknowledges message sent to agent
- `conversation-resolved` - Notifies resolution with feedback request
- `submit-feedback` - Client sends rating and comment
- `feedback-submitted` - Server confirms feedback saved

### Modified Files
**Backend**:
- `src/services/socket.ts` (message routing, handoff, feedback)
- `src/services/ai.ts` (updated AI prompt)
- `prisma/schema.prisma` (added feedback columns)
- `prisma/migrations/` (new migration)

**Frontend**:
- `lib/socket.ts` (fixed backend URL)
- `app/sites/[siteId]/page.tsx` (pass userId)

**Widget**:
- `src/index.ts` (conversation management, feedback UI)
- `src/managers/SocketManager.ts` (new events, methods)
- `src/styles.css` (agent messages, feedback UI)

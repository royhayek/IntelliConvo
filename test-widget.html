Chat Widget Test Page

Instructions

This page tests the embedded chat widget. Make sure:

  • Backend is running on http://localhost:5001
  • Widget server is running on http://localhost:8080 (run npm run serve in widget folder)

Sample Content for Testing

Once the widget loads, try asking questions about your crawled website content to test:

  • Semantic search (finds relevant content from embeddings)
  • AI response generation (uses GPT-4)
  • Real-time streaming (Socket.io)
  • Conversation persistence (stored in database)
